dev-ledger.json 字段说明与导入合并策略
seq 单调递增整数（排序与「谁覆盖谁」的唯一依据）· ts ISO 时间（本地时区，仅展示与时钟异常检测）· task_id 任务 ID · from/to 状态标签 · actor 开发者标识 · evidence 分支/提交/PR/产物 · note 备注/验收结论 · payload_before/payload_after 状态快照（可选）· type 状态流转 / 负责人变更 / 补充记录 · stream 流编号 · task_title 标题。
文件结构：{schema_version, generated_by, updated_at, fields, entries[]}，entries 只追加，不重写历史。
导入合并策略（seq 为准）： ① 按 seq 升序合并，重复条目（seq 相同且内容一致）自动去重； ② 同一任务取 seq 最大 的状态作为当前状态，ts 不参与排序； ③ 导入条目 seq 大于本地该任务最大 seq 时才回放任务字段，更旧的只并入历史、不改当前状态； ④ 同一 seq 指向不同记录 → 保留本地、导入方顺延新 seq 并标红，人工裁定； ⑤ 旧格式无 seq 的条目按 ts 升序接在本地最大 seq 之后，回放时以 ts 兜底； ⑥ ts 倒退或未来 ts 只在状态栏告警「时钟异常」，不改变排序、不阻断操作。 导出文件即下次可直接导入的格式。
