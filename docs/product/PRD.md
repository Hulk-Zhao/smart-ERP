## 1. 概述

### 1.1 定位（一句话）

在客户既有的 ERP、MES、财务、供应商协同之上，提供一层**可审计的跨系统业务执行层**：Agent 在多个系统之间把对账、录入、比价、齐套、排程、异常、报价、月结等事务真正办完，每笔写入有工单、有前像后像、可审批、可回滚。

### 1.2 目标客户

必须同时满足（缺一不进入销售漏斗）：

| 维度 | 条件 |
|---|---|
| 行业 | 离散制造：电子组装（MVP 唯一行业）、装备制造、汽车零部件 |
| 规模 | 营收 3–20 亿元；2–5 个工厂/法人；200–2000 人 |
| 系统 | ≥2 套异构业务系统 + 1 套自研或轻量 MES；有 ERP 开放接口或可读副本 |
| 组织 | 有月度对账/月结考核；由 CFO 或运营负责人承担指标 |

**排除项**：单一厂商全家桶且不混用；流程制造（化工/食品/医药）；营收 < 5000 万小微；要求整体替换现有 ERP 的客户。

### 1.3 三个核心问题（PRD 只解决这三个）

| # | 问题 | 现状 | 本产品交付的解法 |
|---|---|---|---|
| P1 | 跨系统事务没人真正办完 | 员工在 6–10 个系统间搬单据，月末靠人肉比对 | 跨系统写入 + Saga 补偿 + 闭环状态可视（FR-1xx/2xx/3xx） |
| P2 | CIO 不敢让 AI 写生产系统 | 厂商只讲 human-in-the-loop，无审计对象 | Agent 工单 + 前像后像 + 三级回滚 + 双人复核（FR-11xx/13xx/14xx） |
| P3 | CFO 无法为"AI 效果"付钱 | 按席位/按动作，账单不可预测 | 基线采集 + 结果度量 + 封顶计费展示（FR-16xx） |

### 1.4 成功指标（Phase 1 验收口径）

| 指标 | 定义与口径 | 目标 |
|---|---|---|
| 对账差异率改善 | （基线期差异金额/对账总额）−（当期差异金额/对账总额），同期同供应商群 | ≥ 30% 相对下降，至少 2 家客户达标 |
| 单供应商对账工时 | 从触发批次到出具结论的人工分钟数（含补录），按供应商取中位数 | 下降 ≥ 60% |
| 首个闭环上线周期 | 诊断结束日 → 首次正式写入日 | ≤ 6 周 |
| 写入成功率 | 成功写入步数 / 计划写入步数（不含预演失败） | ≥ 99.5% |
| 回滚成功率 | 成功补偿步数 / 应补偿步数（可回滚场景） | 100% |
| 审计覆盖率 | 有工单且有前后像的写动作 / 全部写动作 | 100% |
| 单据直通率 | 未经人工修改即被采纳的单据数 / 总单据数 | ≥ 70% |
| 越权写入 | 红队测试 + 生产环境合计 | 0 |

## 2. 用户与角色

### 2.1 业务角色

| 角色 | 他要什么 | 在系统里做什么 | 权限边界 |
|---|---|---|---|
| **财务对账岗**（主用户） | 月结别拖、差异说得清、付款别错 | 复核对账结论、确认差异归因、确认付款草稿、处理异常队列 | 可复核与修改 W1 结论；不可配置连接器；不可发起实际付款；单笔 > 50 万需上级复核 |
| **采购员 / 采购主管** | 比价有依据、催料有记录、对账不背锅 | 确认比价结论与供应商归属、处理缺单异常、确认委外加工费差异 | 可复核采购类 W1；不可修改已审核订单；供应商银行信息只读 |
| **生产计划 / 车间主管** | 排程可执行、异常有人管、交期敢承诺 | 采纳排程方案、确认改期/改派、处置异常单 | 排程仅采纳权（W0 建议）；改派/延期需计划 + 销售双确认 |
| **IT / CIO** | 系统别乱、权限可控、出事能查 | 配置连接器与字段映射、审批权限变更、导出审计台账、查看拦截记录 | 全部连接器配置权；**无业务复核权**（职责分离）；不可修改工单内容 |
| **CFO / 财务负责人** | 投入有回报、账单可预算 | 查看价值对账与计费、审批高金额处置、批准基线协议 | 只读全量 + 高金额审批；不可配置技术参数 |
| **供应商对接人**（外部，Phase 2） | 知道哪笔没对上 | 接收对账差异卡片、回复争议 | 仅可见本供应商数据；无系统写入权 |

### 2.2 系统角色（权限模型的基础）

| 系统角色 | 说明 | 能否同时是业务角色 |
|---|---|---|
| 发起人（Initiator） | 触发 Agent 或提交单据的人/定时任务 | 是 |
| 复核人（Reviewer） | 对 W1/W2 动作签字 | 是，但不可复核自己发起的 |
| 审批人（Approver） | 超阈值动作的第二签 | 是，需与复核人不同人 |
| 审计只读（Auditor） | 只读工单、台账、指标 | 是，只读 |
| 平台管理员（Admin） | 连接器、映射、许可 | 是，但不可复核业务 |
| 运维（Ops） | 健康度、日志、熔断处置 | 否（内部人员） |

**职责分离硬规则**：同一自然人不得同时作为同一工单的发起人与复核人；不得同时为复核人与审批人；平台管理员不得复核业务动作（FR-1403）。

### 2.3 权限矩阵（角色 × 能力）

| 能力 | 财务对账 | 采购 | 计划/车间 | IT/CIO | CFO | 审计只读 |

| 发起 Agent 任务 | ✓ | ✓ | ✓ | — | — | — |
| 复核 W1 | ✓（财务类） | ✓（采购类） | ✓（生产类） | — | — | — |
| 审批 W2 / 超阈值 | — | — | — | — | ✓（>10 万或触及应付需双人；>50 万 CFO 终签） | — |

| 回滚他人工单 | — | — | — | ✓（需理由） | ✓ | — |
| 连接器与映射配置 | — | — | — | ✓ | — | — |
| 查看审计台账 | 本部门 | 本部门 | 本部门 | 全量 | 全量 | 全量 |
| 导出审计台账 | — | — | — | ✓ | ✓ | ✓ |
| 查看计费与价值 | — | — | — | 只读 | ✓ | 只读 |

## 4. 功能需求

### 4.0 通用规则（所有 FR 默认适用，不在各条重复）

| 编号 | 规则 | 实现约束 |
|---|---|---|
| G-01 | 先预演后写入 | 任何写动作必须先调用 `preview` 产出 diff；预演失败 = 零写入 |
| G-02 | 幂等 | 幂等键 = 场景码 + 业务键（如供应商+期间）+ 行号；重复请求返回首次结果，不重复写入 |
| G-03 | 写入等级 | 等级由「连接器声明」∩「场景配置」取严；Agent 不得自我提升（FR-1406） |
| G-04 | 审批阈值 | 默认：金额 > 10 万或触及应付 → 双人；金额 > 50 万 → 加 CFO；阈值可配但不可低于默认 |
| G-05 | 范围显式 | 任何查询/任务必须带组织、期间、系统范围，缺省不允许执行 |
| G-06 | 证据可下钻 | 任何结论中的数字必须可回溯到「系统 + 单据号 + 字段 + 原文坐标」 |
| G-07 | 熔断 | 单 Agent 1 小时失败率 > 20% 降级 W0；同租户同日 3 次熔断进入只读（FR-1107） |
| G-08 | 追加写 | 工单、审计台账、指标基线一律 append-only，修改以新版本追加 |
| G-09 | 禁止动作 | 永不可创建/改供应商银行账号、新增会计科目、修改已过账凭证、删除单据 |
| G-10 | 只读优先 | 读走只读副本或缓存，写才走 API；接口不可用时读仍可用 |
| G-11 | 时间口径 | 期间按客户会计期间（非自然月）；时区固定 Asia/Shanghai |
| G-12 | 金额精度 | 金额 4 位小数存储、2 位展示；税率 6 位；比较时按容差 0.01 判定相等 |

### M1 跨系统对账与结算（FR-1xx）

#### FR-101 生成对账批次
- **场景**：月末 D-3 定时触发；或财务手动发起指定「供应商 × 期间」
- **前置**：连接器健康度正常；该供应商期间无未关闭批次（有则合并）；主数据映射完整率 ≥ 95%
- **流程**：选定供应商集合 → 校验前置 → 创建批次（状态 `已创建`）→ 生成子任务入队 → 返回批次号与预计行数
- **异常**：映射完整率 < 95% → 拒绝创建并列出缺失映射；已有未关闭批次 → 提示合并或作废旧批次（需理由）
- **写入**：自有对象（对账批次）· 不涉及外部系统 · W0
- **复核**：无需复核（仅生成对象）
- **验收**：给定 52 家供应商，一次发起生成 52 个批次，全部有唯一批次号；重复发起命中幂等，返回原批次

#### FR-102 多源取数与归一
- **场景**：批次创建后自动执行
- **前置**：批次存在；各源系统可读
- **流程**：读 ERP 委外/采购订单与入库 → 读 MES 报工与报废 → 读 WMS 收发料 → 解析供应商对账单（走 FR-401）→ 按五主对象归一（物料/单位/供应商/金额/期间）
- **异常**：任一源不可读 → 标记该批次「待补数据」，不进入匹配；解析失败 → 按 FR-404 转人工；单位换算缺失 → 该行标「换算缺失」
- **写入**：仅写自有单据中心与对账账中间态 · W0
- **复核**：无（但缺数据清单进异常队列 FR-805）
- **验收**：单批次读完 5 类来源，生成可匹配行集合；缺失来源有明确标注与责任人

#### FR-103 三层匹配
- **场景**：取数完成后自动执行
- **前置**：批次状态 = `已取数`
- **流程**：①单据号直配（一致即匹配）→ ②业务键模糊配（物料 + 数量 ± 容差 + 期间）→ ③候选生成（置信度排序，不自动选）
- **异常**：多候选且置信度差 < 0.1 → 不判定，标「匹配歧义」；未匹配 → 进差异清单（缺单类）
- **写入**：自有对象（匹配结果）· W0
- **复核**：歧义行必须人工裁决（FR-806）
- **验收**：金标准样本 500 行，直配 + 模糊配合计匹配率 ≥ 92%；歧义行 100% 可裁决且不误判

#### FR-104 差异计算与七类归因
- **场景**：匹配完成后
- **前置**：匹配结果存在
- **流程**：按行计算数量差/金额差 → 归入七类（单价不一致、数量不符、报废未扣、单位换算、税率口径、缺单、重复计费）→ 输出差异金额、责任方、建议处置
- **异常**：差异率 > 20% 或数量差 > 10 倍 → 标「疑似数据异常」并阻断自动处置；归因置信度 < 0.7 → 归入「待人工归因」
- **写入**：自有对象（差异项）· W0
- **复核**：金额差 > 500 元或差异率 > 2% 的行必须人工确认（FR-107）
- **验收**：归因准确率 ≥ 85%（与人工确认结果比对）；七类可覆盖样本中 ≥ 95% 的差异

#### FR-105 生成付款申请草稿
- **场景**：批次结论为「已平」或「差异已确认」
- **前置**：该批次无未确认差异；供应商未被冻结；应付科目映射存在
- **流程**：汇总应付款 → 生成草稿 payload（供应商、金额、期间、附对账结论引用）→ 预演 → 写入 ERP 应付草稿 → 回写工单
- **异常**：ERB 接口失败 → 重试 3 次后停在断点；金额校验不一致 → 删除草稿并重算，连续 2 次失败熔断该供应商
- **写入**：ERP 应付（付款申请草稿）· **W1**；自有对象（对账结论与草稿关联）
- **复核**：财务必须确认后才在 ERP 提交（系统不代提交）
- **验收**：草稿金额 = 对账结论金额（误差 ≤ 0.01）；一次通过率 ≥ 80%；不得出现重复草稿

#### FR-106 生成差异处置单草稿
- **场景**：差异确认后需要补单/退货/索赔/调账
- **前置**：差异项已确认；处置类型已选
- **流程**：按处置类型组装单据 → 预演 → 写入 ERP 草稿（补单申请/退货申请）或自有对象（索赔/调账建议）→ 关联差异项
- **异常**：目标单据类型在客户系统不支持 → 降级为「处置建议」输出到异常队列；写入失败 → 补偿删除已建草稿
- **写入**：ERP（补单/退货草稿）· **W1**；自有对象（调账建议）· W0
- **复核**：处置金额 > 10 万需双人；索赔类必须采购主管确认
- **验收**：每张处置单可反查差异项与原始证据；删除后差异项状态回退且可重做

#### FR-107 差异复核（并排证据）
- **场景**：差异项进入复核队列
- **前置**：差异项存在且归因已给出
- **流程**：展示「我方（ERP+MES）/ 供应商账单 / 差异」三方并排 → 展示原始证据（报工截图、对账单高亮行、价格协议）→ 复核人选择批准/修改后批准/驳回并填意见
- **异常**：证据缺失 → 不允许批准，只能驳回或转上级；复核人与发起人相同 → 系统拒绝
- **写入**：自有对象（复核意见、修正值）· W1 由后续动作执行
- **复核**：本条即复核点
- **验收**：空意见不可提交；"修改后批准"记录 Agent 建议值、人工修正值、差值三列；差值进入评测样本

#### FR-108 对账批次关闭与重开
- **场景**：批次全部差异关闭；或发现上游数据错误需重开
- **前置**：关闭需无未关闭差异；重开需填写理由并具备高级权限
- **流程**：校验 → 关闭（生成对账结论快照）→ 或重开（旧结论置「已作废」，新建版本）
- **异常**：已生成付款草稿的批次重开 → 必须先撤销草稿，否则拒绝；已对外发送对账确认 → 需人工确认撤回
- **写入**：自有对象（批次状态）· W0；如需撤销草稿走 FR-1302
- **复核**：重开必须由非发起人确认
- **验收**：关闭后批次不可再写入；重开产生新版本号且旧版本可查；作废不删除

#### FR-109 批量执行与断点续跑
- **场景**：一次发起 50+ 批次
- **前置**：批次已入队
- **流程**：按供应商维度并行（并发上限可配，默认 4）→ 每批次独立工单 → 失败不阻塞其他 → 支持从断点续跑
- **异常**：限流命中 → 退避重试并降低并发；单批次失败 3 次 → 标「失败待处理」并通知
- **写入**：同上，按各批次动作决定
- **复核**：无额外复核（沿用各动作）
- **验收**：100 批次在限流约束下全部完成或明确失败；断点续跑不产生重复写入（幂等验证）

#### FR-110 对账结论导出
- **场景**：财务归档、给供应商发送、审计抽样
- **前置**：批次已关闭
- **流程**：选择批次与模板 → 生成 Excel/PDF（含差异明细与证据引用）→ 下载并记录导出行为
- **异常**：含 L3 敏感字段导出 → 需二次确认并记入审计
- **写入**：无（只读导出）
- **复核**：无
- **验收**：导出内容与界面一致；导出行为可在审计台账检索

### M2 委外加工费对账（FR-2xx）

#### FR-201 委外加工费协议维护
- **场景**：新供应商/新料号/协议调价
- **前置**：供应商与物料映射存在
- **流程**：录入单价、计价单位、损耗率上限、生效期间、阶梯价 → 校验区间不重叠 → 保存为版本
- **异常**：区间重叠 → 拒绝并指出冲突版本；无协议 → 允许但该料号对账标记「无协议价」
- **写入**：自有对象（价格协议）· W0（同时提供导出供 ERP 价格条件维护）
- **复核**：价格协议变更需采购主管确认
- **验收**：同一物料同期间只有一份有效协议；历史版本可查

#### FR-202 发料与回收核对
- **场景**：委外发料后、收货时
- **前置**：委外订单存在
- **流程**：取 ERP 委外发料单 + WMS 实发 → 计算应耗（按 BOM 或定额）与实耗 → 生成损耗差异 → 与收货数量对齐
- **异常**：超损耗率上限 → 标「超损耗」并要求供应商说明；无 BOM/定额 → 仅核对发料与回收数量，不做应耗判定
- **写入**：自有对象（损耗差异）· W0
- **复核**：超损耗项必须采购确认
- **验收**：损耗差异可追溯到发料单与收货单；超损耗清单可直接生成索赔建议

#### FR-203 加工费计算
- **场景**：月末结算
- **前置**：协议价存在；报工/收货数量可读
- **流程**：按协议（单价 × 合格数量 + 阶梯调整 − 损耗扣减）计算应付加工费 → 与供应商账单比对
- **异常**：数量口径不一致（报工 vs 收货）→ 输出两套结果并标差异；无协议价 → 阻断并输出缺价清单
- **写入**：自有对象（加工费计算表）· W0
- **复核**：金额 > 10 万双人复核
- **验收**：计算结果可逐行展开到「单价 × 数量 = 金额」；与手工复算误差 ≤ 0.01

#### FR-204 委外损耗索赔建议
- **场景**：超损耗确认后
- **前置**：FR-202 产出超损耗记录
- **流程**：按协议损耗率与材料价计算索赔金额 → 生成索赔建议单 → 进入处置流程
- **异常**：材料价缺失 → 以最近采购价估算并标注；供应商争议 → 转人工协商并记录
- **写入**：自有对象（索赔建议）· W0；如需扣款，仅生成 ERP 应付调整草稿 · **W1**
- **复核**：任何扣款动作必须采购 + 财务双签
- **验收**：索赔金额计算过程可审计；扣款草稿与索赔单一一对应

#### FR-205 委外在外料跟踪
- **场景**：月末盘点在外料
- **前置**：委外订单未关闭
- **流程**：汇总各供应商在外料数量与金额 → 与供应商确认 → 生成在外料台账
- **异常**：账实不符 → 输出差异清单，不自动调账
- **写入**：自有对象（在外料台账）· W0
- **复核**：财务确认后作为暂估依据（联动 FR-1002）
- **验收**：台账可按供应商/物料/期间钻取；与 ERP 委外余额差异有解释

#### FR-206 委外批次异常单
- **场景**：来料不合格、数量短少、延期
- **前置**：收货或质检记录存在
- **流程**：生成异常单 → 关联处置建议（退货/让步接收/返工）→ 通知采购与供应商
- **异常**：需退货但已入库 → 只能走退货草稿，不可删除入库单
- **写入**：自有对象（异常单）· W0；退货草稿 · **W1**
- **复核**：让步接收必须品质 + 采购双确认
- **验收**：异常单可反查质检记录；处置动作留痕

#### FR-207 委外对账结论合并
- **场景**：同一供应商同时有采购与委外业务
- **前置**：两类批次均已完成
- **流程**：合并为一张供应商对账结论（采购货款 + 委外加工费 − 索赔 − 退货）→ 生成单一付款草稿
- **异常**：两类批次存在未确认差异 → 不合并，分别出结论
- **写入**：ERP 应付草稿（合并后）· **W1**
- **复核**：合并后金额 > 50 万需 CFO 审批
- **验收**：合并前后金额勾稽平衡；不产生两张重复付款草稿

### M3 采购三单匹配（FR-3xx）

#### FR-301 三单取数与关联
- **场景**：发票到达或月末批量
- **前置**：采购订单、收货单、发票三类数据可读（发票可来自 FR-401）
- **流程**：以采购订单行为锚点 → 关联收货行 → 关联发票行 → 形成三单对照
- **异常**：收货无订单 → 缺单类差异；发票无收货 → 标「提前开票」；部分收货 → 按已收数量匹配
- **写入**：自有对象（三单对照）· W0
- **复核**：无
- **验收**：三单关联率 ≥ 90%（金标准样本）；未关联行 100% 有原因码

#### FR-302 三单匹配规则
- **场景**：对照建立后
- **前置**：主数据映射完整
- **流程**：按「物料/数量容差/单价容差/税率/期间」五项规则判定通过与否 → 输出直通/差异
- **异常**：容差未配置 → 使用默认（数量 ±0.5%、单价 ±0.1%、金额 ±1 元）并标注
- **写入**：自有对象（匹配结果）· W0
- **复核**：不通过项进入 FR-303
- **验收**：直通率可计算并按客户/期间统计；规则命中原因可解释

#### FR-303 差异分类与处置
- **场景**：匹配不通过
- **前置**：存在差异行
- **流程**：分类（价差/量差/税差/缺单/重复开票）→ 给出处置建议（调价单/补收货/换票/挂账）
- **异常**：重复开票 → 强制阻断并提示发票号重复；价差超 5% → 升级采购主管
- **写入**：自有对象（差异与建议）· W0；处置单据草稿 · **W1**
- **复核**：价差超 5% 或金额超 10 万需复核
- **验收**：每类差异有明确处置路径与责任人

#### FR-304 发票登记草稿
- **场景**：发票需在 ERP 登记
- **前置**：发票结构化数据就绪（FR-401）；供应商与采购订单可匹配
- **流程**：预演 → 写发票登记草稿 → 关联采购订单与收货
- **异常**：发票号重复 → 拒绝；税额不平 → 拒绝并输出差额
- **写入**：ERP（发票登记草稿）· **W2**（Phase 2 起，MVP 为 W1 需人工确认）
- **复核**：MVP 阶段全部人工确认；Phase 2 起阈值内免审
- **验收**：登记草稿与发票影像一一对应；不得出现重复登记

#### FR-305 暂估与冲回联动
- **场景**：月末有收货未开票
- **前置**：收货单存在、发票未到
- **流程**：识别未开票收货 → 生成暂估清单 → 交 FR-1002 执行
- **异常**：上期暂估本期未冲回 → 报警并列出差异
- **写入**：自有对象（暂估清单）· W0
- **复核**：由月结流程统一复核（FR-1002）
- **验收**：暂估清单与未开票收货一一对应，无遗漏

#### FR-306 供应商对账确认（对外）
- **场景**：己方结论生成后需供应商确认
- **前置**：批次已出结论
- **流程**：生成对外对账卡片/PDF → 通过 IM 或邮件发送 → 记录确认/争议
- **异常**：供应商超 3 个工作日未回 → 提醒并升级采购
- **写入**：自有对象（确认状态）· 通知类
- **复核**：无（外部确认，不改我方数据）
- **验收**：确认状态可查；争议内容进入差异项

#### FR-307 三单匹配报表
- **场景**：月度复盘
- **前置**：期间数据完整
- **流程**：按供应商/采购员/差异类型统计直通率与差异金额 → 导出
- **异常**：期间未关闭 → 标注「进行中」
- **写入**：无
- **复核**：无
- **验收**：报表口径与 FR-302 一致，可与价值仪表盘勾稽

### M4 单据录入（FR-4xx）

#### FR-401 单据上传与识别
- **场景**：财务/采购上传 PDF、图片、扫描件；或从 IM/邮件收取
- **前置**：文件类型在白名单（pdf/jpg/png/xlsx）；大小 ≤ 20MB
- **流程**：上传 → 病毒扫描 → 版面分析 → 分类（对账单/送货单/发票/领料单）→ 结构化抽取 → 返回字段与置信度
- **异常**：分类置信度 < 0.8 → 要求人工选类型；文件损坏 → 拒绝并提示；超 20MB → 拒绝
- **写入**：文件存储（原始影像，不可变）；自有对象（抽取结果）· W0
- **复核**：置信度 < 0.85 的字段必须人工确认（FR-405）
- **验收**：三类单据分类准确率 ≥ 95%；字段抽取准确率 ≥ 97%（数值类 ≥ 99%）

#### FR-402 字段抽取与坐标回链
- **场景**：识别完成后
- **前置**：分类完成
- **流程**：抽取关键字段（单号、日期、供应商、物料、数量、单价、金额、税额）→ 每字段存值、置信度、原文坐标（页码 + 包围盒）
- **异常**：字段缺失 → 标记空缺而非猜测；多页表格 → 按行合并并保留页码
- **写入**：自有对象 · W0
- **复核**：低置信字段高亮
- **验收**：任一字段可点击回跳到影像对应位置；空缺字段不得被填充为 0

#### FR-403 主数据匹配
- **场景**：抽取完成后
- **前置**：主数据可读
- **流程**：按名称/编码/别名匹配供应商与物料 → 给 Top3 候选与置信度
- **异常**：候选置信度接近（差 < 0.1）→ 不自动选；无候选 → 标「主数据缺失」并进异常队列
- **写入**：自有对象（匹配建议）· W0
- **复核**：首次出现的供应商/物料必须人工绑定（FR-1404）
- **验收**：匹配准确率 ≥ 95%；歧义 100% 人工裁决

#### FR-404 解析失败处理
- **场景**：抽取置信度低于阈值或结构无法识别
- **前置**：已尝试自动解析
- **流程**：整批转入「待补录」队列 → 标出缺失字段与原因 → 提供手工录入表单（带影像对照）
- **异常**：同一供应商连续 3 期解析失败 → 生成「模板建议」给供应商（记录在案）
- **写入**：自有对象 · W0
- **复核**：人工补录即为复核
- **验收**：解析失败率可统计；补录后单据可正常进入对账

#### FR-405 单据草稿生成
- **场景**：字段确认后建单
- **前置**：关键字段非空且已确认；主数据已绑定
- **流程**：按类型组装 payload → 预演 diff → 写 ERP 草稿 → 关联影像与抽取记录
- **异常**：金额 > 10 万 → 强制全行复核；写入失败 → 保留抽取结果，允许重试（幂等）
- **写入**：ERP（入库单/领料单/发票登记草稿）· **W1**
- **复核**：金额 > 10 万或首供应商必复核
- **验收**：草稿字段与影像一致率 100%（抽检 50 张）；无重复建单

#### FR-406 重复单据检测
- **场景**：同一张单被多次上传
- **前置**：文件哈希或业务四元组（供应商 + 单号 + 金额 + 日期）可比对
- **流程**：哈希命中或四元组命中 → 拒绝并给出已存在单据链接
- **异常**：四元组相同但确为不同批次（客户编码习惯问题）→ 允许带原因强制通过并留痕
- **写入**：无（拒绝写入）
- **复核**：强制通过需复核人确认
- **验收**：重复上传 100% 被拦截或留痕；无静默重复
### M5 采购比价（FR-5xx，Phase 2）

#### FR-501 询价发起与回收
- **场景**：请购单生成；或采购主动询价
- **前置**：请购物料存在；供应商清单可用
- **流程**：生成询价单 → 按供应商渠道发送（IM/邮件/门户）→ 回收报价（结构化表单或文件 → FR-401 解析）→ 归一化（含税/运费/币种/有效期）
- **异常**：报价缺少必要口径 → 标记「口径不全」，不参与比价；超有效期 → 自动排除
- **写入**：自有对象（询价单、报价快照）· W0
- **复核**：无
- **验收**：报价归一化后可横向比较；口径不全的报价不进入排名

#### FR-502 历史价与基线
- **场景**：比价前准备
- **前置**：历史采购数据可读
- **流程**：按物料/供应商/期间计算历史成交价分布（中位数、P25/P75、最近成交）→ 标记异常历史（方差过大）
- **异常**：样本 < 3 笔 → 只给「无有效基线」；方差 > 阈值 → 标注「基线不可信」
- **写入**：自有对象（价格基线）· W0
- **复核**：基线首次生成需采购确认
- **验收**：任一报价可与历史基线对比并给出偏离度；基线不可信时有明确标注

#### FR-503 替代料与供应商资格
- **场景**：比价时存在替代料或多供应商
- **前置**：替代料关系与供应商资格数据存在
- **流程**：查替代料可用性（工艺/品质已认证）→ 查供应商资格与履约（交期、质量、历史差异率）→ 生成候选集
- **异常**：替代料未经品质认证 → 只做「参考展示」，不进入推荐；供应商资格过期 → 排除
- **写入**：自有对象（候选集）· W0
- **复核**：替代料首次使用需工艺/品质确认（系统不做技术判断）
- **验收**：推荐候选 100% 具备有效资格；未认证替代料有显式警示

#### FR-504 比价结论与下单建议
- **场景**：候选集就绪
- **前置**：至少 2 个有效报价
- **流程**：按综合得分（价格 60% / 交期 20% / 履约 20%，权重可配）排序 → 生成推荐与理由 → 风险提示（单一供应商、价格高于基线 15%）→ 输出下单建议
- **异常**：仅 1 个有效报价 → 输出「单一来源」提示并要求理由；价格高于基线 15% → 强制升级审批
- **写入**：自有对象（比价结论）· W0；ERP 采购订单草稿（人工确认后）· **W1**
- **复核**：所有比价结论必须采购确认；异常价差需主管审批
- **验收**：得分计算可展开；推荐理由包含每项得分来源；下单草稿与结论一一对应

#### FR-505 比价台账与降本归因
- **场景**：月度复盘
- **前置**：期间比价完成
- **流程**：统计比价覆盖率、平均降本率、单一来源比例 → 与基线对比 → 输出降本金额（仅统计可归因部分）
- **异常**：无基线 → 不计算降本，只统计覆盖率
- **写入**：无
- **复核**：无
- **验收**：降本金额口径可下钻到每笔订单；不可归因部分单独列示

### M6 库存与齐套预警（FR-6xx，Phase 2）

#### FR-601 多级 BOM 展开与齐套计算
- **场景**：工单下达前；或每日定时
- **前置**：BOM 完整（无断链）；库存与在途可读
- **流程**：按工单展开多级 BOM → 汇总毛需求 → 扣减可用库存（含已分配）与在途 → 计算缺口与最早可用日
- **异常**：BOM 断链 → 拒绝出结论，输出断链位置；循环 BOM → 拒绝并报警
- **写入**：自有对象（齐套结论）· W0
- **复核**：无（结论供计划员使用）
- **验收**：齐套结论可逐层展开到子件；断链 100% 被识别

#### FR-602 缺口归因
- **场景**：存在缺口
- **前置**：齐套结论存在
- **流程**：归因四类（未采购 / 在途延迟 / 被其他工单占用 / 账实不符）→ 给责任人与建议
- **异常**：归因置信度 < 0.7 → 标「待查」；账实不符 → 只输出清单，不调账（G-09）
- **写入**：自有对象 · W0
- **复核**：账实不符一律人工处理
- **验收**：四类归因覆盖 ≥ 90% 缺口；账实不符清单可直接生成盘点任务

#### FR-603 缺料预警与推送
- **场景**：缺口影响交期
- **前置**：齐套结论 + 工单交期可知
- **流程**：按影响交期天数分级（红/橙/黄）→ 推送计划员与采购 → 记录确认
- **异常**：同一物料连续 3 日预警未处理 → 升级至部门负责人
- **写入**：自有对象；IM 通知
- **复核**：升级动作需人确认
- **验收**：预警分级规则可配；推送可达且可追溯

#### FR-604 补货与调拨建议
- **场景**：缺口需外部补充
- **前置**：缺口确认；安全库存策略存在
- **流程**：按策略生成采购申请建议或跨厂调拨建议（含运费与时效估算）
- **异常**：无安全库存策略 → 只给「建议补货量 = 缺口」，不猜策略
- **写入**：ERP 采购申请草稿 / 调拨申请草稿 · **W1**
- **复核**：调拨影响其他订单时必须计划员确认
- **验收**：建议量可解释（缺口、批量、提前期）；草稿可撤销

#### FR-605 库存预留与释放
- **场景**：工单锁定物料
- **前置**：可用量足够；优先级规则存在
- **流程**：按订单优先级分配预留 → 回写 ERP/WMS 预留标记 → 记录分配依据
- **异常**：预留冲突（挤占高优先级）→ 拒绝并提示冲突工单；预留后工单取消 → 自动释放
- **写入**：ERP/WMS（预留标记）· **W2**（超阈值需审批）
- **复核**：跨订单抢占必须计划员确认
- **验收**：预留可撤销；冲突 100% 被拦截；释放后可用量即时恢复

#### FR-606 账实不符清单
- **场景**：系统库存与盘点/实物不符
- **前置**：存在盘点记录或人工上报
- **流程**：生成差异清单（物料/库位/系统值/实物值/差异）→ 指派盘点复核 → 记录结论
- **异常**：差异率 > 5% → 提示可能存在系统性数据问题（联动数据体检）
- **写入**：自有对象 · W0（**永不自动调账**）
- **复核**：必须仓库 + 财务共同确认后由人在 ERP 调账
- **验收**：Agent 全程零库存写入；清单可作为审计证据

### M7 生产排程（FR-7xx，Phase 3）

#### FR-701 排程输入校验
- **场景**：发起排程
- **前置**：工单池、工艺路线、工作中心能力、日历可读
- **流程**：校验标准工时覆盖率、能力数据完整性、物料齐套状态 → 输出可排程范围与数据缺口
- **异常**：标准工时缺失率 > 30% → 拒绝排程；能力日历缺失 → 用默认班次并标注
- **写入**：自有对象（校验报告）· W0
- **复核**：无
- **验收**：数据缺口清单可直接分派补齐；缺失率计算口径固定

#### FR-702 确定性求解
- **场景**：校验通过
- **前置**：输入完整
- **流程**：调用 APS 内核（Frepple 路线）求解 → 输出工单序列、设备占用、预计完工 → 记录求解参数与耗时
- **异常**：无可行解 → 输出「最小违约方案」并列出必须牺牲的订单；超时 → 降级为未来 3 天局部重排并说明
- **写入**：自有对象（排程版本）· W0
- **复核**：无（结果待采纳）
- **验收**：同输入可复现（固定随机种子）；无解时不输出伪方案

#### FR-703 方案解释与影响评估
- **场景**：方案生成后
- **前置**：排程版本存在
- **流程**：生成自然语言解释（瓶颈、关键路径、为何这样排）→ 插单影响评估（哪几单延期几天）→ 代价对比（加班/外协/拆批）
- **异常**：解释与求解结果不一致 → 以求解结果为准并记录告警
- **写入**：自有对象 · W0
- **复核**：涉及客户交期的评估必须抄送销售
- **验收**：影响评估可量化到「订单 × 延期天数」；解释不得包含求解器未使用的约束

#### FR-704 方案采纳
- **场景**：计划员确认方案
- **前置**：方案已生成
- **流程**：计划员点击采纳 → 系统生成「写入计划」交人工执行或经标准流程写 MES/ERP（**Agent 不直写**）
- **异常**：ERP/MES 已有变更（版本冲突）→ 拒绝采纳并提示重排
- **写入**：MES/ERP 工单日期 · **W0**（由人工发起的标准写入，不计入 Agent 写入）
- **复核**：采纳动作本身即人工确认
- **验收**：采纳记录含操作人、时间、方案版本；未采纳方案不影响任何系统

#### FR-705 排程版本管理
- **场景**：多次排程
- **前置**：存在历史版本
- **流程**：版本列表（时间、参数、KPI 预测）→ 对比两版本差异 → 回退到指定版本
- **异常**：回退到已被采纳的版本 → 需重新确认
- **写入**：自有对象 · W0
- **复核**：回退需计划员确认
- **验收**：任一版本可复算；版本间差异可导出

### M8 异常处置（FR-8xx，Phase 3）

#### FR-801 异常接入
- **场景**：MES 报警、质检不合格、设备停机、供应商延期、缺料预警
- **前置**：来源系统可读；异常类型在字典内
- **流程**：接收事件 → 去重（同对象同类型 30 分钟内合并）→ 建异常单 → 关联受影响工单与订单
- **异常**：未知类型 → 进入「未分类」队列并提示扩展字典
- **写入**：自有对象（异常单）· W0
- **复核**：无
- **验收**：事件到异常单 ≤ 1 分钟；重复事件不重复建单

#### FR-802 影响面计算
- **场景**：异常单建立
- **前置**：工单与订单关联可读
- **流程**：计算受影响工单、订单、客户、金额、预计延期天数 → 输出影响清单
- **异常**：关联关系缺失 → 标「影响未知」并要求补录，不做推测
- **写入**：自有对象 · W0
- **复核**：影响客户清单必须销售可见
- **验收**：影响清单可下钻到订单行；未知项显式标注

#### FR-803 处置方案生成
- **场景**：影响面已知
- **前置**：可用资源（替代设备/替代料/外协产能）可读
- **流程**：生成 ≤3 个方案（改期/改派/外协转移/加急采购）→ 每个给代价（延期天数、成本增加、风险）→ 推荐并说明
- **异常**：所需资源不可用 → 不生成该方案（预演阶段校验）；无可行方案 → 输出「需人工决策」
- **写入**：自有对象（方案）· W0
- **复核**：方案必须计划员选择
- **验收**：每个方案含可量化代价；不可行方案不得出现

#### FR-804 跨系统处置执行
- **场景**：方案确认后
- **前置**：方案已选；预演通过
- **流程**：按 Saga 顺序执行（ERP 改期草稿 → MES 改派申请 → 委外转移草稿 → 通知）→ 每步校验 → 失败逆序补偿
- **异常**：部分失败 → 自动补偿已执行步骤并转人工；客户已确认新交期 → 不自动改，升级人工（FR-1305）
- **写入**：ERP 改期/改量草稿 · **W1**；MES 改派申请 · **W1**；委外转移单草稿 · **W1**
- **复核**：改期需计划 + 销售；委外需采购确认价格
- **验收**：跨 3 系统处置全部成功或全部回滚；半成功状态 0 例（演练验证）

#### FR-805 异常分诊队列
- **场景**：异常单进入待处理
- **前置**：异常单存在
- **流程**：按「影响金额 × 客户等级 × SLA」排序 → 支持分派给 Agent 或人 → SLA 计时与超期提醒
- **异常**：无建议动作 → 不允许入队（须先由 Agent 给出至少一条建议或明确标「需人工判断」）
- **写入**：自有对象 · W0
- **复核**：分派需接收人确认
- **验收**：排序规则可解释；超期异常 100% 可检索

#### FR-806 根因聚合
- **场景**：周期性复盘
- **前置**：异常单积累 ≥ 1 个周期
- **流程**：按类型/物料/供应商/设备聚合 → 输出 Top 根因与建议改进（如要求供应商按模板开单）
- **异常**：样本过少 → 只出清单不给结论
- **写入**：自有对象 · W0
- **复核**：改进建议需业务负责人确认后执行
- **验收**：根因分布可下钻到原始异常单

### M9 报价（FR-9xx，Phase 3）

#### FR-901 询价接入与相似订单检索
- **场景**：客户询价到达
- **前置**：询价含图纸/规格/数量/交期
- **流程**：解析询价 → 检索相似历史订单（物料/工艺/规格相似度）→ 输出可比订单集

#### FR-902 成本拆解
- **场景**：可比订单确定
- **前置**：BOM/工艺/工时/材料价/外协价可读
- **流程**：拆分材料、工时、外协、制造费用、损耗、运费、税率 → 计算总成本与区间（无历史时给区间不给点值）

- **写入**：自有对象（成本版本）· W0
- **复核**：成本版本必须成本会计确认
- **验收**：成本构成可逐项下钻；估算项有明确标识与来源

#### FR-903 三档报价与敏感性
- **场景**：成本确认后
- **前置**：毛利底线策略存在
- **流程**：生成保底价/建议价/理想价 → 敏感性分析（材料 ±5%、汇率 ±3% 对毛利影响）→ 报价单草稿
- **异常**：低于毛利底线 → 强制升级总经理；无底线策略 → 阻断并要求配置
- **写入**：ERP/CRM 报价单草稿 · **W1**
- **复核**：销售负责人 + 成本会计双签
- **验收**：三档价差可解释；敏感性结果可复算

#### FR-904 报价版本与作废
- **场景**：报价需调整或已发出
- **前置**：存在报价版本
- **流程**：已发出报价不可修改，只能作废并新建版本 → 版本标注差异原因
- **异常**：作废已中标报价 → 需商务负责人审批
- **写入**：自有对象 · W0；新版本草稿 · **W1**
- **复核**：作废需审批
- **验收**：报价编号永不复用；历史版本全量可查

#### FR-905 报价复盘
- **场景**：中标/丢单/交付完成
- **前置**：结果已知
- **流程**：记录报价 vs 实际成本、中标/丢单原因 → 沉淀为知识库
- **异常**：结果未回填 → 提醒责任人
- **写入**：自有对象 · W0
- **复核**：复核由销售负责人完成
- **验收**：毛利偏差可按报价人/产品线统计

### M10 月结辅助（FR-10xx，Phase 2）

#### FR-1001 月结检查清单

- **异常**：前置步骤未完成 → 阻断后续并说明依赖

- **场景**：存在收货未开票
- **前置**：FR-305 暂估清单就绪；科目映射完整
- **流程**：生成暂估入库单草稿 → 生成上期冲回草稿 → 校验借贷平衡 → 输出凭证草稿
- **异常**：借贷不平 → 拒绝生成并输出差额与可疑原因；映射缺失 → 整批暂停并输出缺映射清单

- **前置**：分摊规则已配置并经财务批准
- **流程**：按规则计算分摊额 → 生成分摊表 → 凭证草稿
- **异常**：规则变更 → 需重新审批；分摊后合计不等于差异总额 → 拒绝（不允许尾差自动塞入）
- **写入**：ERP 凭证草稿 · **W1**
- **复核**：财务负责人复核
- **验收**：分摊结果可复算；尾差显式列出

#### FR-1004 期间锁定校验
- **场景**：月结完成前
- **前置**：清单完成度 100%
- **流程**：校验是否仍有未确认差异、未处理异常 → 输出可否锁定结论
- **异常**：存在未确认项 → 不允许锁定并列出清单
- **写入**：无（仅校验与提示；实际锁定在客户 ERP 执行）
- **复核**：财务负责人确认
- **验收**：校验结果与清单一致；不得出现"提示可锁定但仍有差异"

#### FR-1005 月结天数度量
- **场景**：期间关闭后
- **前置**：期间有起止时间记录
- **流程**：计算月结天数（期间结束日 → 实际关账日）→ 与基线对比 → 写入指标仓
- **异常**：关账日无法确定 → 标「数据缺失」，不估算
- **写入**：自有对象（指标）· W0
- **复核**：无
- **验收**：口径固定且可复算；缺失时不产生虚假指标

#### FR-1006 月结阻塞升级
- **场景**：月结临近仍有阻塞项
- **前置**：检查清单存在阻塞项
- **流程**：按剩余天数分级提醒 → 升级至财务负责人 → 记录处置
- **异常**：责任人离职/调岗 → 自动改派至其上级
- **写入**：自有对象；IM 通知
- **复核**：升级需接收人确认
- **验收**：升级链路可追溯；无"无人负责"的阻塞项
### M11 Agent 工单（FR-11xx）

#### FR-1101 工单创建
- **场景**：Agent 被定时/事件/人工触发
- **前置**：触发方具备发起权限（FR-1401）；场景已注册
- **流程**：生成工单号（`AT-YYYYMMDD-NNNN`）→ 写入场景、发起人、触发方式、业务键 → 生成执行计划（步骤序列）→ 状态置 `计划中`
- **异常**：同业务键已有运行中工单 → 返回既有工单（幂等），不新建
- **写入**：自有对象（工单）· append-only
- **复核**：无
- **验收**：工单号全局唯一；同业务键并发 10 次仅产生 1 张工单

#### FR-1102 执行计划与预演
- **场景**：工单已创建
- **前置**：计划中每一步已声明目标系统、动作、预期影响、补偿动作
- **流程**：逐步调用 `preview` → 汇总 diff → 若任一步无补偿动作且等级 > W0 → 拒绝执行
- **异常**：预演失败 → 工单置 `已终止`，零写入；预演结果与预期差异过大（金额偏差 > 5%）→ 置 `待确认` 交人判断
- **写入**：无（预演不落库）
- **复核**：偏差过大时人工确认
- **验收**：预演阶段 0 写入（通过数据库审计验证）；无补偿动作的高危动作 100% 被拒

#### FR-1103 审批流触发
- **场景**：预演通过
- **前置**：动作等级与金额命中阈值（G-04）
- **流程**：按等级生成审批链（单人 / 双人 / 加 CFO）→ 推送给复核人 → 记录审批意见
- **异常**：复核人与发起人相同 → 系统拒绝并改派；超 24 小时未处理 → 提醒并升级
- **写入**：自有对象（审批记录）
- **复核**：本条即复核点
- **验收**：审批链与阈值配置一致；自审 100% 被拦截

#### FR-1104 执行与步骤校验
- **场景**：审批通过
- **前置**：审批已完成
- **流程**：按序执行步骤 → 每步带幂等键调用 `write` → 每步执行后校验（值/金额/状态）→ 校验通过进下一步
- **异常**：单步失败 → 重试 3 次（指数退避）→ 仍失败进入补偿（FR-1105）；校验不一致 → 立即停止并补偿
- **写入**：按各动作等级（W0–W2）
- **复核**：无（已审批）
- **验收**：每步有独立日志（入参/出参/耗时/幂等键）；失败步骤有明确错误码

#### FR-1105 补偿执行
- **场景**：执行中失败或人工触发回滚
- **前置**：存在已成功步骤
- **流程**：按逆序调用 `compensate` → 每步校验 → 全部成功置 `已回滚`；任一步失败置 `需人工处置`
- **异常**：补偿动作本身不可用（外部已生效）→ 置 `已锁定` 并生成人工处置任务（FR-1305）
- **写入**：补偿动作（删除草稿/红冲/撤销）· 等级不高于原动作
- **复核**：人工触发的回滚需填写原因；`需人工处置` 必须指派责任人
- **验收**：可回滚场景回滚成功率 100%；补偿过程每一步可追溯

#### FR-1106 工单查询与下钻
- **场景**：复核、审计、排障
- **前置**：有查看权限（§2.3）
- **流程**：按工单号/业务键/供应商/期间/状态/发起人检索 → 详情展示时间线、变更影像、影响面、审批链
- **异常**：跨部门越权查看 → 拒绝并记录
- **写入**：无
- **复核**：无
- **验收**：任一写动作可在 3 次点击内定位到工单；检索结果 ≤ 2 秒返回

#### FR-1107 熔断与降级
- **场景**：失败率异常
- **前置**：有失败统计
- **流程**：1 小时失败率 > 20% → 该 Agent 降级 W0 并告警；同日 3 次熔断 → 租户只读；恢复需人工解除
- **异常**：误触发 → 允许管理员提前解除并留痕；解除后 1 小时内再次触发 → 冷却期延长至 24 小时
- **写入**：自有对象（熔断状态）
- **复核**：解除熔断需管理员确认
- **验收**：熔断生效 ≤ 1 分钟；降级期间写入 0 次

#### FR-1108 工单导出
- **场景**：内审/外审抽样
- **前置**：导出权限
- **流程**：按条件导出（工单号、时间、动作、前后像、审批人、金额、系统）→ 生成 CSV/XLSX + 校验哈希
- **异常**：导出含 L3 数据 → 二次确认并记录
- **写入**：无（只读）
- **复核**：无
- **验收**：导出字段覆盖审计所需全部要素；哈希可校验完整性

### M12 连接器管理（FR-12xx）

#### FR-1201 连接器注册与自描述
- **场景**：接入新系统
- **前置**：管理员权限；系统可访问
- **流程**：填写系统类型/版本/地址/鉴权 → 调用 `describe()` 拉取对象与字段 → 生成连接器卡片 → 标注接入级别（L1/L2/L3）与安全等级（A/B）
- **异常**：`describe` 失败 → 不允许保存；版本不支持 → 标记「实验性」并限制最高写入等级为 W0
- **写入**：自有对象（连接器配置）
- **复核**：连接器启用需安全负责人确认（A 级可自审，B 级强制）
- **验收**：连接器卡片含系统、版本、级别、等级、限流、最后同步；实验性连接器无法进入 W1

#### FR-1202 动作白名单配置
- **场景**：连接器注册后
- **前置**：`describe` 返回动作列表
- **流程**：勾选允许的动作与可写字段 → 保存为白名单版本 → 网关按白名单加载工具
- **异常**：试图勾选 G-09 禁止项 → 系统置灰且不可提交；白名单为空 → 该连接器只能读
- **写入**：自有对象（白名单）
- **复核**：白名单变更需双人确认（IT 主管 + 安全）
- **验收**：未在白名单的动作，Agent 候选集中不可见（不可仅靠运行时拦截）；禁止项 100% 置灰

#### FR-1203 字段映射与权威源
- **场景**：接入与变更
- **前置**：连接器可用
- **流程**：建立我们的字段 ↔ 客户字段映射 → 指定权威源 → 保存映射版本 → 记录最近校验时间
- **异常**：映射冲突（同一字段两个权威源）→ 拒绝保存；必填映射缺失 → 映射完整率下降并在批次前置校验中阻断
- **写入**：自有对象（映射）
- **复核**：映射变更需管理员确认
- **验收**：任一字段可查权威源与校验时间；冲突映射无法保存

#### FR-1204 连通性与兼容性测试
- **场景**：上线前、版本变更后
- **前置**：连接器配置完成
- **流程**：执行读/预演/写测试动作集 → 输出通过率与耗时 → 记录版本指纹
- **异常**：写测试不得在生产库执行 → 必须使用沙箱或专用测试单号段；无可写测试环境 → 只跑只读测试并标注
- **写入**：测试用草稿（带 `TEST-` 前缀，自动清理）
- **复核**：结果由管理员确认
- **验收**：测试用例覆盖读/预演/写/补偿四类；测试数据 100% 清理

#### FR-1205 健康度与限流监控
- **场景**：持续运行
- **前置**：连接器启用
- **流程**：采集最后同步时间、失败率、限流余量、平均耗时 → 超阈值告警
- **异常**：连续 2 周失败率 > 2% → 升级 P1 风险；限流余量 < 20% → 自动降低并发
- **写入**：自有对象（监控指标）
- **复核**：告警由运维处置
- **验收**：健康度在看板可见且延迟 ≤ 1 分钟；降并发自动生效

#### FR-1206 版本变更监控
- **场景**：厂商升级
- **前置**：已记录版本指纹
- **流程**：周期性比对指纹 → 变更时告警 → 触发兼容性测试（FR-1204）→ 输出受影响映射与动作
- **异常**：变更导致动作失效 → 自动将该连接器最高写入等级降为 W0 并通知
- **写入**：自有对象（变更记录）
- **复核**：恢复等级需管理员确认
- **验收**：版本变更 100% 被检测；降级自动执行且可追溯

#### FR-1207 拦截记录
- **场景**：越权请求发生
- **前置**：网关拦截生效
- **流程**：记录请求方、目标系统、动作、被拦字段、时间 → 汇总到连接器卡片
- **异常**：短时间大量拦截 → 视为攻击信号并告警安全
- **写入**：自有对象（拦截日志，append-only）
- **复核**：安全事件由安全负责人复核
- **验收**：每次拦截可查；拦截计数在界面可见（04 P6）

#### FR-1208 连接器暂停与吊销
- **场景**：安全事件、合同终止、切换系统
- **前置**：管理员权限
- **流程**：暂停（保留配置，停止调用）→ 或吊销（清除凭据引用）→ 记录原因
- **异常**：暂停时有运行中工单 → 等待当前步骤结束再暂停，或强制中止并补偿
- **写入**：自有对象（连接器状态）；凭据存储（吊销）
- **复核**：吊销需双人确认
- **验收**：吊销后 5 分钟内所有调用失败且不可恢复；凭据无残留

### M13 审计与回滚（FR-13xx）

#### FR-1301 变更影像记录
- **场景**：任何写动作成功
- **前置**：动作已执行
- **流程**：采集写前快照（before）与写后快照（after）→ 计算字段级 diff → 关联工单 → 写入不可变存储
- **异常**：无法读取写前快照 → 该动作不允许执行（预演阶段阻断）；diff 计算失败 → 存原始快照并标「diff 缺失」
- **写入**：自有对象（影像，append-only）
- **复核**：无
- **验收**：审计覆盖率 100%；任一字段变更可定位到具体步骤

#### FR-1302 自动回滚（一级）
- **场景**：W1 草稿类动作需撤销
- **前置**：动作类型在「可自动回滚」清单内
- **流程**：调用补偿动作 → 校验目标状态 → 更新工单状态 → 记录回滚耗时
- **异常**：目标已被人工提交（草稿变正式）→ 拒绝自动回滚，升级为二级；连续 2 次回滚失败 → 熔断该场景
- **写入**：补偿动作
- **复核**：人工发起需原因；系统自动触发需留痕
- **验收**：15 分钟内完成；回滚后系统状态与写前一致（字段级比对）

#### FR-1303 人工确认回滚（二级）
- **场景**：已审核单据、已占用库存
- **前置**：存在可红冲/反向的目标
- **流程**：生成反向单据草稿（红冲/退回）→ 展示影响 → 人工确认 → 写入 → 校验
- **异常**：目标期间已锁定 → 禁止回滚，只能在下期冲销；客户不同意红冲 → 转人工协商
- **写入**：ERP 反向单据草稿 · **W1**
- **复核**：必须复核（财务类需会计 + 主管）
- **验收**：4 小时内提交草稿；红冲单据与原单据强制关联

#### FR-1304 不可回滚告警（三级）
- **场景**：外部已生效（已付款、已发货、已通知供应商、已过账）
- **前置**：动作被标记为不可补偿
- **流程**：不改数据 → 生成应急处置任务 → 通知责任人 → 记录处置结论
- **异常**：责任人未在 SLA 内处理 → 升级
- **写入**：自有对象（处置任务）
- **复核**：处置结论需负责人确认
- **验收**：不可回滚动作 100% 有处置任务与责任人；无静默失败

#### FR-1305 回滚影响评估
- **场景**：发起回滚前
- **前置**：工单存在已成功步骤
- **流程**：列出将撤销的步骤、可自动/需人工/不可回滚分类、受影响单据与金额、预计耗时
- **异常**：影响含外部已生效动作 → 显式高亮并禁止一键回滚
- **写入**：无
- **复核**：评估结果需回滚发起人确认
- **验收**：评估与实际执行一致；不可回滚项在执行前即被标出

#### FR-1306 审计台账
- **场景**：内审/外审/监管
- **前置**：工单与影像已积累
- **流程**：按人/系统/金额/期间/动作类型检索 → 生成台账视图 → 导出（FR-1108）
- **异常**：跨期数据量大 → 分页与异步导出
- **写入**：无
- **复核**：无
- **验收**：台账与工单明细一致；异步导出 10 万条 ≤ 10 分钟

#### FR-1307 审计留存与哈希链
- **场景**：长期归档
- **前置**：影像写入
- **流程**：每条记录计算哈希并链入上一条 → 按客户配置留存期（默认 10 年）→ 到期归档不删除
- **异常**：哈希链断裂 → 告警安全事件；存储不足 → 提前告警
- **写入**：自有对象（哈希链）
- **复核**：留存期变更需 CFO 确认
- **验收**：可校验任意时点台账完整性；留存期符合客户会计档案要求

#### FR-1308 事故处置联动
- **场景**：P0/P1 事故
- **前置**：事件已识别
- **流程**：冻结租户写入 → 定位相关工单 → 批量评估影响 → 生成处置方案（回滚/红冲/通知）→ 记录复盘
- **异常**：冻结影响客户业务 → 提供「只读模式」保障查询可用
- **写入**：自有对象（事故记录）
- **复核**：解冻需 CTO + 客户确认
- **验收**：冻结生效 ≤ 1 分钟；事故记录含时间线、影响面、根因、改进项

### M14 权限与审批（FR-14xx）

- **异常**：人员不足导致无法满足 → 允许「跨组织复核人」并记录（不得同人）
- **写入**：自有对象（校验结果）
- **复核**：无

#### FR-1404 主数据绑定审批

- **前置**：FR-403 产出候选
- **流程**：提交绑定申请 → 采购/财务审批 → 写入映射 → 生效
- **异常**：绑定错误 → 允许解绑（需审批）并追溯已使用该映射的对账结论

#### FR-1406 写入等级约束

- **前置**：连接器与场景均声明等级
- **流程**：取两者较低值 → 与动作实际需求比对 → 不足则拒绝
- **异常**：场景声明 W2 但连接器仅支持 W1 → 按 W1 执行并提示；Agent 请求升等级 → 拒绝并记录

#### FR-1407 W3 硬禁止

- **流程**：动作分类器识别为 W3 → 直接拒绝并记录尝试 → 通知安全
- **异常**：无例外路径（不可通过配置、白名单、脚本开启）
- **写入**：无（拒绝）
- **复核**：无
- **验收**：代码层无 W3 执行路径（代码审计验证）；尝试记录 100% 可查

#### FR-1408 权限变更审计
- **场景**：角色/范围/阈值变更
- **前置**：变更已提交
- **流程**：记录变更前后值、操作人、审批人、时间 → 写入审计台账 → 通知相关人
- **异常**：紧急变更（安全事件）→ 允许事后补审批并标注
- **写入**：自有对象（审计）
- **复核**：事后补审批需安全负责人确认
- **验收**：任一权限变更可追溯到人；紧急变更 100% 有补审批记录

### M15 界面（FR-15xx）

#### FR-1501 工作台
- **场景**：日常入口
- **前置**：用户有权限
- **流程**：状态结论条（期间进度、异常数、影响金额）→ 待处理卡片（按影响金额 × 截止时间排序，含一句话建议与主操作）→ 指标条（≤6 个，带基线对比）→ 后台 Agent 任务（可折叠）
- **异常**：无待办 → 明确文案（如"本月 52 家已全部对平，下批 12-03 生成"），不显示"暂无数据"
- **写入**：无（操作为跳转或内联）
- **复核**：无
- **验收**：首屏可见 ≥5 张待办卡片；任一卡片主操作可在侧栏完成不跳页

#### FR-1502 对话入口
- **场景**：自然语言发起或追问
- **前置**：已选择范围（组织/期间/系统）
- **流程**：输入 → 结论卡（含主操作）→ 追问 → 证据卡 → 写入型操作弹出 diff 确认
- **异常**：未选范围 → 阻断并要求选择；超出业务范围 → 标准拒绝话术；无权限数据 → 提示范围外
- **写入**：经确认后触发的写入按对应 FR 等级
- **复核**：写入前二次确认（diff 预览）
- **验收**：纯文字结论 ≤ 3 行；每个数字可点开证据；未选范围无法提问

#### FR-1503 Agent 任务详情
- **场景**：查看/审批/回滚
- **前置**：有权限
- **流程**：标题（工单号、对象、状态、影响金额、跨系统数）→ 状态机进度条 → 时间线（每步可展开：接口、字段、耗时）→ 变更影像（字段级 diff）→ 影响面 → 操作区（按权限显隐）
- **异常**：工单执行中 → 操作区禁用回滚（避免半途中断）；已锁定 → 显示"不可回滚"原因
- **写入**：按操作
- **复核**：操作区即复核入口
- **验收**：状态机 6 状态可视化；diff 可逐字段对比；回滚前必展示回滚计划

#### FR-1504 复核与审批中心
- **场景**：批量复核
- **前置**：队列有任务
- **流程**：队列（按风险排序）→ 详情（三方并排 + 证据 + 判断区）→ 批准/修改后批准/驳回/转上级 → 批量操作（仅限合格任务）
- **异常**：空意见提交 → 阻断；批量含不合格任务 → 拒绝并标出；第二复核人默认隐藏第一人意见（防锚定）
- **写入**：按动作
- **复核**：本条即复核点
- **验收**：批准必填意见；批量门槛生效；双人复核互不可见直至都提交

#### FR-1505 异常队列
- **场景**：需人工判断的异常
- **前置**：异常已入队
- **流程**：分诊（类型分布 + 排序）→ 单条（一句话描述、缺失项、建议动作）→ 执行建议或分派 → 根因 Top3
- **异常**：无建议动作 → 不入队；忽略需填原因并进下期复检
- **写入**：按建议动作
- **复核**：分派需接收人确认
- **验收**：排序规则可解释；每条异常必须含建议动作或"需人工判断"标记

#### FR-1506 连接器管理 + 报表与结算 + IM 卡片
- **场景**：管理员配置、CFO 看价值、移动办公
- **前置**：对应权限
- **流程**：连接器卡片（级别/等级/白名单/健康度/拦截记录）→ 映射表 → 报表页（价值对账 + 计费 + 封顶进度 + 审计导出）→ IM 卡片（一件事一卡、金额与后果、两个按钮）
- **异常**：连接器异常 → 卡片红色且禁用相关 Agent；报表口径缺失 → 显示"口径待确认"而非估算
- **写入**：连接器配置为 W0（配置类）；IM 卡片内批准 > 1 万跳转工作台
- **复核**：连接器启用需安全确认
- **验收**：白名单与禁止项可见；封顶进度常显；IM 卡片批准流程 ≤ 2 次确认

### M16 价值度量与结算（FR-16xx）

#### FR-1601 基线采集
- **场景**：诊断期（上线前）
- **前置**：客户同意口径；历史数据可读（≥3 个期间）
- **流程**：按口径采集对账差异率、单供应商工时、月结天数、直通率 → 生成基线快照 → 冻结（写入不可变）→ 生成基线协议附件
- **异常**：历史不足 3 期 → 标注"基线可靠性低"并由双方书面接受；口径无法统一 → 按 R1 有效对账行口径冻结（工时仅作参照）
- **写入**：自有对象（基线）· append-only
- **复核**：基线必须 CFO 书面确认
- **验收**：基线可复算、可导出、冻结后不可改（仅可新增版本）

#### FR-1602 当期度量
- **场景**：每期结束
- **前置**：期间数据完整
- **流程**：按同口径计算当期指标 → 与基线对比 → 输出变化与折算价值 → 写入指标仓
- **异常**：数据不完整 → 标"度量不完整"且不计费；口径被客户质疑 → 冻结计费并转人工核对
- **写入**：自有对象（指标）
- **复核**：财务确认后进入计费
- **验收**：每个指标可下钻到原始单据；不可计算时明确标注而不估算

#### FR-1603 增量归因
- **场景**：结果费结算前
- **前置**：基线与当期均有效
- **流程**：三重校验（前后对比 + 未接入组织对照 + 人工抽检 ≥5%）→ 输出可归因增量 → 生成归因说明
- **异常**：无对照组 → 仅用前后对比并降低归因系数（保守）；抽检偏差 > 10% → 以抽检结果为准并重算
- **写入**：自有对象（归因结果）
- **复核**：归因结果需客户书面确认
- **验收**：归因过程可复算；保守原则（疑不归因）写入规则

#### FR-1604 计费展示与封顶
- **场景**：月度/年度查看
- **前置**：归因完成
- **流程**：计算平台订阅 + 结果费（有效对账行 × 单行单价）→ 校验封顶（结果费 ≤ 订阅 × 3）→ 展示明细与剩余额度 → 导出账单草稿
- **异常**：超封顶 → 按封顶计并标注"已封顶"；争议 → 标记"待核对"，不进入账单
- **写入**：自有对象（账单草稿）
- **复核**：CFO 确认
- **验收**：账单金额 = 明细合计；封顶永远生效；争议项单独列示

#### FR-1605 价值看板导出
- **场景**：季度复盘、续费谈判
- **前置**：数据完整
- **流程**：生成价值报告（基线 vs 当期、折算金额、Agent 质量、驳回原因分布）→ 导出 PDF
- **异常**：含未确认归因 → 报告标注"初稿"
- **写入**：无
- **复核**：客户成功负责人确认
- **验收**：报告数字与报表页一致；初稿有显式水印

## 5. Agent 行为规格

### 5.0 通用约定

**状态机（全部 Agent 共用，不允许自定义状态）**

```
计划中 ──预演通过──> 待审批 ──批准──> 执行中 ──全部成功──> 校验中 ──通过──> 已完成
  │                    │                 │                              └──不一致──> 补偿中
  │                    └──驳回──> 已驳回   ├──单步失败(重试耗尽)──> 补偿中
  ├──预演失败──> 已终止（零写入）          └──外部已生效──> 已锁定（仅告警）
  └──偏差>5%──> 待确认（人工判断）
补偿中 ──全部成功──> 已回滚 / ──任一失败──> 需人工处置
```

**失败分类（F1–F8，全部 Agent 复用，便于统一埋点）**

| 码 | 分类 | 典型原因 | 统一处理 |
|---|---|---|---|
| F1 | 数据缺失 | 源系统无数据/期间无记录 | 阻断并输出缺失清单（不猜） |
| F2 | 解析失败 | 影像模糊/格式异常 | 转人工队列，保留原始件 |
| F3 | 匹配歧义 | 多候选置信度接近 | 不下结论，交人裁决 |
| F4 | 主数据缺失/未绑定 | 新供应商/新物料 | 触发 FR-1404 绑定流程 |
| F5 | 接口失败 | 超时/限流/权限 | 指数退避重试 3 次，失败进补偿 |
| F6 | 校验不一致 | 写入值与预期不符 | 立即停止并补偿 |
| F7 | 并发冲突 | 版本号变化/锁占用 | 中止并重新取数（不覆盖） |
| F8 | 外部已生效 | 已付款/已通知/已过账 | 不改数据，生成处置任务 |

**契约约定**
- 所有 Agent 入参必须含 `scope{org_id, period, system_ids}`；缺任一字段拒绝执行（G-05）。
- 所有出参必须含 `ticket_id`、`status`、`evidence[]`（每条证据含 `system / doc_no / field / coord`）。
- 金额字段一律为 `{amount: decimal(18,4), currency, tax_included}`，禁止裸数字。
- 置信度统一 `0.00–1.00`，低于 0.70 视为不可用（不得作为结论输出）。

| 失败处理 | 借贷不平→拒绝并给差额与可疑原因；映射缺失→整批暂停给清单；与上期不匹配→报警不自动调平 |
| 补偿动作 | `delete_voucher_draft(id)`；`void_accrual_draft(id)` |
| 熔断条件 | 1 小时失败率 > 20%；连续 2 期出现不平 |
| 度量 | 月结天数、暂估准确率、月末返工次数 |

## 6. 界面需求

页面结构、原则与线框见 [04-界面与交互](./04-界面与交互.md) §3。本节只补三类开发必需信息：**字段级要求、状态展示、空态/错误态、IM 卡片交互**。

### 6.1 字段级要求（按页面）

**P1 工作台**

| 元素 | 字段 | 规则 |
|---|---|---|
| 状态结论条 | `period_progress{done,total}`、`open_exceptions`、`amount_at_risk` | 文案模板："月末对账进行中：{done}/{total} 家已平"；数字可点开明细 |
| 待办卡片 | `object_name`、`key_amount`、`suggestion`（≤30 字）、`deadline`、`priority` | 排序 = 影响金额 × 紧急度；主操作 ≤1 个，次操作 ≤1 个 |
| 指标条 | `metric_name`、`current`、`baseline`、`delta_pct`、`trend` | 最多 6 个；无基线时显示"无基线"且不显示 delta |
| 后台任务 | `agent`、`ticket_id`、`progress`、`current_step` | 进度以步骤计，不以百分比臆造 |

**P3 Agent 任务详情**

| 元素 | 字段 | 规则 |
|---|---|---|
| 头部 | `ticket_id`、`scene`、`status`、`diff_amount`、`systems_count`、`duration` | 跨系统数必须显示；`status` 用状态机枚举值，不自造文案 |
| 时间线 | `ts`、`system`、`action`、`read_fields[]`、`written_fields[]`、`latency_ms` | 写入行必须带「查看 diff」入口 |
| 变更影像 | `object`、`field`、`before`、`after`、`delta` | 金额/数量差异带正负与颜色；同时用 +/− 符号（无障碍） |
| 影响面 | `amount_affected`、`docs_count`、`systems[]`、`touches_fund`、`touches_inventory` | `touches_fund=true` 时操作区加警示条 |
| 操作区 | `approve`、`reject`、`rollback`、`export` | 按 §2.3 权限显隐；`已锁定` 时 `rollback` 置灰并给原因 |

**P4 复核与审批中心**

| 元素 | 字段 | 规则 |
|---|---|---|
| 队列项 | `object`、`diff_amount`、`risk_tags[]`、`deadline` | 风险标签枚举：金额>1万、首次合作、触及应付、低置信 |
| 三方并排 | `item`、`ours_qty`、`supplier_qty`、`delta`、`ours_amount`、`supplier_amount` | 差异列固定显示；空值显示 `—` 不显示 0 |

| 判断区 | `decision`、`comment`（必填）、`corrected_value?` | 空意见阻断；修正值必须与建议值同时记录 |

**P6 连接器管理**

| 元素 | 字段 | 规则 |
|---|---|---|
| 连接器卡 | `system`、`version`、`access_level`、`security_level`、`health`、`last_sync`、`fail_rate`、`rate_limit_left` | `security_level=B` 时卡片必须显示"仅允许 W1" |
| 白名单 | `action`、`fields[]`、`enabled`、`forbidden` | 禁止项置灰不可勾选（G-09） |
| 映射表 | `our_field`、`their_field`、`authority`、`last_verified`、`conflicts` | 冲突数 >0 时高亮并可跳转处理 |
| 风险提示 | `type`、`count`、`detail_link` | 拦截记录不可隐藏，只能展开 |

**P7 报表与结算**

| 元素 | 字段 | 规则 |
|---|---|---|
| 价值对账 | `metric`、`baseline`、`current`、`delta`、`value_converted`、`caliber_link` | 必须可点开口径；折算价值无口径时为 `—` |

### 6.2 状态展示

| 状态域 | 枚举 | 展示要求 |
|---|---|---|
| 工单 | 计划中/待审批/执行中/校验中/已完成/已回滚/需人工处置/已锁定/已终止/已驳回 | 颜色 + 图标 + 文字三重标识；颜色不作为唯一区分 |

| 连接器 | 正常/告警/降级/暂停/吊销 | 降级时全局提示受影响 Agent |
| 异常 | 待分诊/处理中/已关闭/已忽略 | 忽略项必须显示复检日期 |

### 6.3 空态与错误态（每个页面必须实现）

| 场景 | 文案要求 | 必须有 |
|---|---|---|
| 无待办 | 说明当前状态与下次动作时间（如"已全部对平，下批 12-03 生成"） | 一句状态 + 一个可执行链接 |
| 无数据（筛选后） | "当前范围内无记录" + 建议放宽范围的操作 | 一键清除筛选 |
| 权限不足 | "该数据不在你的可见范围" + 申请入口 | 申请按钮（可选） |
| 连接器不可用 | "ERP 连接异常，数据可能不是最新，最后同步 {ts}" | 重试 + 查看连接器 |
| Agent 失败 | 失败原因码（F1–F8）+ 影响 + 下一步（重试/转人工/回滚） | 转人工按钮 |
| 加载超时 | "正在读取 {system}，已等待 {n}s" | 可取消 |
| 数据不完整 | 明确指出"缺哪个系统的哪类数据" | 缺失清单 |

### 6.4 IM 卡片交互

| 项 | 规范 |
|---|---|
| 卡片要素 | 标题（对象 + 待办动作）、关键金额、一句话后果、2 个按钮（查看 / 操作） |
| 操作按钮 | 批准/驳回类：点击后在 IM 内二次确认；`amount > 10,000` 时二次确认改为跳转工作台（P4） |

| 可达性 | 发送失败重试 3 次后回落到邮件；仍失败则在站内信记录 |

### 7.2 质量校验规则（数据体检与运行期共用）

| 规则 ID | 对象 | 规则 | 严重级 | 违反处理 |
|---|---|---|---|---|
| DQ-01 | 供应商 | 同一 `tax_no` 不得对应多个有效编码 | 高 | 阻断对账，要求合并 |
| DQ-02 | 物料 | `base_unit` 不得为空；单位换算必须闭合（A→B→A 一致） | 高 | 该物料相关行标"换算缺失" |
| DQ-03 | BOM | 不得断链、不得循环引用 | 高 | 拒绝齐套/委外计算 |
| DQ-04 | 价格协议 | 同供应商同物料同期间不得有多份有效协议 | 高 | 拒绝使用，提示冲突版本 |
| DQ-05 | 单据 | 金额 = Σ(数量 × 单价) ± 容差 0.01 | 中 | 标"金额不平"，人工确认 |
| DQ-06 | 单据 | 税率 ∈ 客户允许税率集合 | 中 | 标"税率异常" |
| DQ-07 | 库存 | 可用量 ≥ 0（负库存需有解释单据） | 中 | 标"负库存"，禁用于齐套结论 |
| DQ-08 | 汇率 | 期间内必须有生效汇率 | 中 | 标注使用日期，禁止外推 |
| DQ-09 | 主数据 | 供应商/物料映射完整率 ≥ 95% | 高 | 阻断批次创建（FR-101 前置） |
| DQ-10 | 对账单 | 单号 + 供应商 + 金额 + 日期 四元组唯一 | 高 | 拒绝重复建单（FR-406） |

### 7.3 数据缺失降级策略（总原则：宁可不出结论，不可出错结论）

| 情形 | 降级动作 | 禁止行为 |
|---|---|---|
| 单一源系统不可读 | 标"数据不完整"，暂停该批次；已完成的只读部分保留 | 用历史数据填充当期 |
| 主数据未绑定 | 进入绑定流程，相关行挂起 | 按名称模糊自动绑定 |
| 解析失败 | 转人工补录（带影像对照） | 用模型猜测字段 |
| 指标数据不足 | 显示"无法计算"并说明缺什么 | 估算后当作实际值 |
| 历史不足 3 期 | 基线标"可靠性低"并由双方书面接受 | 用 1 期数据充当基线 |
| 连接器降级（版本变更） | 该连接器最高等级降为 W0 | 继续写入并事后校验 |

## 9. 依赖与假设

### 9.1 外部依赖

| 依赖 | 用途 | 若不可用的影响 |
|---|---|---|
| 客户 ERP 开放接口（L1）或只读副本（L2） | 读写主数据与单据 | 降级为 W0 或无法接入（N9 不做 L3，MVP） |
| 客户 MES 接口 | 报工/报废/工单 | 委外对账无法完整（只做采购侧） |
| 企微/钉钉开放平台 | 卡片与审批 | 退化为邮件 + 站内信，移动场景失守 |
| OCR/文档解析能力 | 对账单/发票结构化 | 直通率下降，人工补录比例上升 |
| 大模型（商用 API 或本地） | 归因/解释/对话 | 确定性规则仍可跑，解释能力与对话入口失效（NFR-A-04） |
| 客户 KMS/Vault | 凭据托管 | 无法满足 NFR-S-05，需客户接受 B 级安全等级 |

### 9.2 关键假设及其对需求优先级的影响

| 假设 | 若不成立 | 受影响需求 | 调整动作 |
|---|---|---|---|
| **A1**：目标客群中 ≥2 套异构系统的比例 ≥ 40% | 定位失效（01 §8 证伪条件 1） | M1/M2/M3 全部 | 停止 S1/S4 投入，转向"单一系统增强"或重做定位 |
| **A2**：CIO 对第三方写入的接受度 ≥ 30% | 只能做只读 | FR-105/106/304/405/604/605/804（全部 W1+） | 降级为 W0 建议 + 客户侧 RPA，S3 的审计需求仍保留但价值下降 |
| **A3**：对账环节可释放工时足以支撑 R1 单行定价（封顶参照） | 计费模型失效 | FR-1603/1604 | 改为纯订阅；FR-1601/1602 仍保留（用于客户成功） |
| **A4**：客户对账单格式相对稳定（≥70% 可用模板解析） | 录入成本过高 | FR-401/402/404、S2 | 前置"供应商模板治理"服务，否则客户 ROI 不成立 |
| **A5**：ERP 接口限流足以支撑月末批量 | 批量跑不完 | FR-109、NFR-P-02 | 改为错峰 + 增量水位 + 只读副本承担读 |
| **A6**：客户愿意接受"我们不做总账"的边界 | 需求膨胀为 ERP 替换 | §3.2 N1 | 拒绝项目；不接受则不进销售漏斗 |

**优先级规则**：A1/A2 为 P0（决定是否开工）；A3 为 P1（决定计费）；A4/A5/A6 为 P2（决定交付方式）。假设验证结果必须在 Phase 1 的 Go/No-Go 评审中书面记录。
